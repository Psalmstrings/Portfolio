Project Overview

CampusMart is a hyper-localized, mobile-first marketplace built to organize student trade within Nigerian higher education institutions. The system enables students to buy and sell textbooks, electronics, dorm essentials, fashion items, and campus services safely inside their own university ecosystem.

Starting with three premier institutions in Lagos State—University of Lagos (UNILAG) in Akoka, Yaba College of Technology (YABATECH) in Yaba, and Lagos State University (LASU) in Ojo—CampusMart replaces ephemeral social media chats with structured product indexing, campus hostel filtering, and transparent seller accountability.

Figure 2.1: CampusMart marketplace discovery hero and product browsing interface.
02

The Problem Solved

Commerce in Nigerian universities is massive but severely fragmented. Students rely on informal WhatsApp groups, temporary status updates, and scattered Telegram channels:

✕ The Fragmentation Challenges

  • Ephemeral Content: WhatsApp group messages and status posts disappear within 24 hours, burying products beneath unrelated group chatter.
  • Zero Search Capability: A student looking for a specific engineering textbook or mini-fridge cannot search or filter by hostel location or price.
  • Campus Scam Vulnerabilities: Anonymous sellers without institutional attribution exploit informal groups with fake deposit requests.
  • Poor Seller Analytics: Student entrepreneurs have no visibility into how many peers viewed their products or initiated buying inquiries.

✓ The CampusMart Solution

  • Structured Catalog & Search: Persistent searchable listings with 14 categories, condition filters, and campus-specific location tags.
  • Verified Student Profiles: Department, academic level, and campus attribution attached to every seller profile.
  • Direct WhatsApp Handoff: One-click click-to-chat pre-filling listing titles and recording buyer engagement metrics.
  • Administrative Moderation: Moderation queue where all newly submitted listings enter a pending status to prevent spam and scams.

Core Implemented Features

  • Dynamic Campus Architecture: Built to seamlessly expand beyond UNILAG, YABATECH, and LASU to any Nigerian institution (e.g., OAU, UI, FUTA, LASUED) via database configuration without code changes.
  • Anti-ReDoS Safe Search: Sanitized regex utility escaping special characters in search queries to prevent catastrophic regex backtracking attacks.
  • Interactive Image Uploader: Multi-image client previews with instant removal and Cloudinary cloud CDN integration.
  • Favorites & Wishlist Management: Persistent user favorites saved to MongoDB with instantaneous optimistic UI toggling.
  • Automated Telemetry: Automatic view counter increments and click-tracking endpoints (whatsappClicks, phoneClicks).
  • Insecure Direct Object Reference (IDOR) Protection: Strict server-side ownership verification ensuring sellers can only modify or delete their own listings.

System Architecture & Data Models

CampusMart is engineered with a clean modular separation between frontend presentation, API controllers, and database models:

CampusMart Full-Stack Topology MERN Architecture

React 19, React Router v7, Tailwind CSS v4, Lucide Icons, Axios instance with automatic JWT Authorization header injection. Mobile-first two-column card grid.
Backend API
Node.js / Express.js REST API with Helmet security headers, CORS origin whitelist, Multer file upload stream, and custom error handling middleware.

Cloudinary cloud image storage with local fallback buffer handling and automated image optimization.

08

Engineering Decisions & Security Measures

1. ReDoS Mitigation in Campus Search Security Implementation

User input in search fields can be weaponized with catastrophic regular expressions (e.g. nested quantifiers like (a+)+$) causing server event-loop stalls. I implemented a strict character escaping helper before passing search terms into MongoDB $regex filters, ensuring guaranteed linear execution time.

2. WhatsApp Handoff over In-App Messaging Product Strategy

Building an in-app chat system creates delivery delays, push-notification reliability issues, and battery drain on low-end Android phones. By delegating conversations directly to WhatsApp via pre-filled URLs while tracking clicks server-side, student buyers and sellers converse on the app they already check constantly, drastically increasing transaction close rates.

3. Forced Admin Password Rotation Access Hardening

To eliminate default credential exploitation on initial deployment, the administrative authentication pipeline flags accounts with default credentials, blocking administrative queries until the root password is cryptographically updated.
